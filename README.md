A versão 1.3.14/build 144 adota a marca NutrileBoreal. Aplicativo anteriormente chamado NutriMentor; identificadores e endereços atuais são preservados para atualização sem apagar dados.

Cada release inclui APK Android, instalador Windows x64, portátil Windows x64, arquivo Linux x64, SHA256SUMS e downloads.json. Os pacotes Windows/Linux estão disponíveis para validação; empacotamento não comprova execução em todas as distribuições. Consulte as notas de cada release.

Este repositório contém somente distribuição e documentação pública. Código-fonte privado. Não há dados clínicos reais neste repositório. A troca de marca não equivale à concessão de registro no INPI.
